# Cycluna — native rebuild (this repo: `cycluna-app`, PUBLIC)

## What Cycluna is
A menstrual-cycle + moon-phase tracker: cycle/phase prediction, moon phases, an
**end-to-end-encrypted journal**, mood & headache logs, shareable cycle snapshots,
and reminders. It is being **rebuilt as native iOS (SwiftUI) + Android (Jetpack
Compose)** on top of a **Kotlin Multiplatform (KMP) shared core**, backed by a
**self-owned Cloudflare backend** — migrating OFF the original Lovable + Supabase
web app.

## The three repos (siblings under `WorkoutTimer/`)
- **`cycluna-app`** (this repo, **PUBLIC**): KMP shared core + native apps. **No secrets** — only the public Cloudflare Worker URL.
- **`cycluna-backend`** (**PRIVATE**): Cloudflare Workers + D1 schema + migration tooling. Not built yet. Full plan: `../cycluna-backend/docs/native-migration-plan.md`.
- **`cycluna-moon-flow`** (**ARCHIVE — do not modify**): the original Lovable/Vite/React + Supabase web app. **Behavioral reference only** — we port logic *from* here.

## The web app is the behavioral reference
When porting, the source of truth is `../cycluna-moon-flow/src/lib/*`. Match behavior
exactly wherever it touches persisted data. Key files:

| Web reference | Native target | Status |
|---|---|---|
| `moon.ts` | `shared` `Moon.kt` | ✅ ported |
| `cycle.ts` | `shared` `Cycle.kt` | ✅ ported |
| `phaseContent.ts` | phase copy (native layer, not core) | ⏳ |
| `crypto.ts` / `letterCrypto.ts` | journal `enc:v1` AES-GCM via `expect/actual` | ⏳ |
| `passkey.ts` (WebAuthn) | native passkey APIs (ASAuthorization / Credential Manager) | ⏳ |
| `push.ts` (web-push/VAPID) | **replaced** by APNs (iOS) + FCM (Android) | ⏳ |

⚠️ **JS `Math.round` is half-up**; Kotlin's `roundToInt` is half-to-even. The port
uses `floor(x + 0.5)` to match the web app exactly. Preserve this in any numeric port.

## Architecture rules
- **`shared/` = pure domain logic only.** No UI, no platform APIs. Swift/Android call it.
- **Keep the core LEAN.** Domain models only — UI copy/colors live in the *native* layer,
  NOT the core. (We deliberately dropped `colorVar`/`hormoneHighlight` from `Phase`.)
- **Platform-native** (per platform): all UI, charts, passkeys, secure key storage
  (Keychain / Keystore), push, on-device reminders. Use **`expect/actual`** for crypto
  and secure storage so the format/logic is written once, implemented natively.
- **UI-first**: build screens, let the data model *emerge*, then design the D1 schema.
  Do **not** faithfully port the old Supabase schema — there are **0 users**, so no data
  migration; the old schema is a checklist of concepts only.

## Stack / toolchain (verified working)
- **Kotlin 2.2.0**, Gradle wrapper **8.11.1**, `kotlinx-datetime` 0.6.1
- Build/test JVM: **Temurin JDK 17** — NOT the Homebrew JDK 26 (too new for this Gradle).
  Always set: `JAVA_HOME=/Library/Java/JavaVirtualMachines/temurin-17.jdk/Contents/Home`
- iOS: **Xcode 26**, deployment target **iOS 17**. The Xcode project is **generated by
  XcodeGen** from `iosApp/project.yml` (edit the yml, not the `.xcodeproj`).

## Layout
```
shared/src/commonMain/kotlin/app/cycluna/core/
    Moon.kt         synodic moon-phase math
    Cycle.kt        cycle-day / phase prediction (pure, takes explicit `today`)
    CyclunaCore.kt  Swift-friendly facade (String/Int returns; hides kotlinx-datetime)
    security/KeyVault.kt   expect: secure string storage contract
shared/src/iosMain/kotlin/app/cycluna/core/security/KeyVault.ios.kt  actual: Keychain
shared/src/jvmMain/kotlin/app/cycluna/core/security/KeyVault.jvm.kt  actual: in-memory (tests)
shared/src/commonTest/kotlin/app/cycluna/core/   MoonTest, CycleTest, security/KeyVaultTest
iosApp/
    project.yml            XcodeGen spec  →  iosApp.xcodeproj
    iosApp/iOSApp.swift, ContentView.swift
    iosApp/PrivacyInfo.xcprivacy   Apple privacy manifest (keep accurate as data use grows)
    iosApp/Info.plist              generated by XcodeGen; has ITSAppUsesNonExemptEncryption
```

Info.plist is an **explicit** file (XcodeGen `info:` block), NOT auto-generated —
edit it via `iosApp/project.yml` `info.properties`, then `xcodegen generate`.

## Commands
```bash
export JAVA_HOME=/Library/Java/JavaVirtualMachines/temurin-17.jdk/Contents/Home

# Run the shared-core unit tests (fast, no simulator)
./gradlew :shared:jvmTest

# Link the iOS simulator framework
./gradlew :shared:linkDebugFrameworkIosSimulatorArm64

# Regenerate the Xcode project after editing iosApp/project.yml
cd iosApp && xcodegen generate

# Build the iOS app (the Xcode build's pre-build script builds the KMP framework;
# JAVA_HOME is hard-coded in project.yml so Xcode GUI builds work too)
xcodebuild -project iosApp/iosApp.xcodeproj -scheme iosApp \
  -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' build
```

## iOS ↔ shared interop notes
- Kotlin `object X` → Swift `X.shared`. Kotlin `Int` → Swift `Int32`.
- Kotlin default arguments do **not** cross to Swift — pass all args.
- To avoid exposing `kotlinx-datetime` types to Swift, add String/Int-returning
  wrappers in `CyclunaCore.kt` (e.g. dates passed as ISO `yyyy-MM-dd` strings).

## Compliance & security
Cycluna is a **reproductive-health app** → App Store Guideline 5.1.3 + heightened
privacy law. Design for it from day one. Living checklist: **`COMPLIANCE.md`**.
Already in place: no-secrets-in-client, Keychain `KeyVault`, privacy manifest,
encryption declaration. Must design into the backend API: **account deletion**,
**data export**, **Sign in with Apple** (mandatory if Google is offered).

## Design fidelity + platform standards (guiding principle)
Match the **web app's visual identity + content**, keep **iOS ≈ Android**, but
implement with each platform's **standards** (HIG nav, native controls, accessibility,
Dynamic Type). Shared *logic* → KMP core (identical on both). Shared *design* → token/
spec system rendered natively (NOT a pixel-copy of the web DOM). The web app in
`../cycluna-moon-flow` is the visual reference (see `MoonWheel.tsx`, `PhaseCard.tsx`,
`Home.tsx`, `index.css` tokens).
